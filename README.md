# herbertjacby.com

Personal portfolio of Herbert Jacby, Senior Front-End Developer.

Built with Next.js (App Router, static export) and TypeScript. All content lives in `src/data/profile.ts`.

## Scripts

- `npm run dev`: local dev server on http://localhost:3000
- `npm run build`: static build into `out/`
- `npm run typecheck`: TypeScript check

## Deploy

Any static host works. Build command `npm run build`, publish directory `out`.
